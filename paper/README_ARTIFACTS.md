# Paper C - Overleaf artifacts

Final LaTeX artifacts for Paper C, generated by
`experiments/export_paper_c_latex_artifacts.py` exclusively from the
real pipeline outputs:

- `results/tables/baseline_results.csv` (rows with `model in {persistence, arima}`)
- `results/tables/lgbm_results.csv` (rows with `model = lgbm`)

The script does not retrain any model. It does not read any
`paper_c_*` intermediate file. If either input is missing or required
model rows are absent, the script aborts with an explicit error and
writes nothing.

## Files to upload to Overleaf

Upload these files preserving the directory layout:

1. `paper/tables.tex`
2. `paper/results_snippets.tex`
3. `paper/figures/fig_paper_c_rmse_skill.png`
4. `paper/figures/fig_paper_c_alpha_vr.png`

## How to insert in `main.tex`

In the preamble (after `\usepackage{graphicx}` and `booktabs`):

```latex
\input{results_snippets}
```

Inside the Results section:

```latex
\input{tables}
```

The figures are referenced from `results_snippets.tex` with
`\label{fig:rmse}` and `\label{fig:alpha}` and expect the PNGs under
`figures/`.

## Macros

`results_snippets.tex` defines six count macros, each computed from the
real CSVs at export time (no hardcoding). The script also writes a
`% Counts derived from real outputs (audit block)` comment block above
the `\newcommand` lines so the file is self-auditable:

- `\ArimaBetterCount`        — cells where `rmse_arima < rmse_persistence`
- `\LGBMBetterCount`         — cells where `rmse_lightgbm < rmse_persistence`
- `\LGBMBeatsArimaCount`     — cells where `rmse_lightgbm < rmse_arima`
- `\LGBMLowerAlphaCount`     — cells where `alpha_lightgbm < alpha_arima`
- `\ArimaGainCollapseCount`  — cells where `alpha_arima < 0.95`
- `\LGBMGainCollapseCount`   — cells where `alpha_lightgbm < 0.95`

`alpha` is `kge_alpha` from `src/evaluation/metrics.py::horizon_profile`.

## Regeneration sequence

From the repository root, in this order:

```bash
python3 experiments/run_baseline.py   # writes results/tables/baseline_results.csv
python3 experiments/run_lgbm.py       # writes results/tables/lgbm_results.csv
python3 experiments/export_paper_c_latex_artifacts.py
```

The export step overwrites `paper/tables.tex`, `paper/results_snippets.tex`,
this README, and the two PNGs under `paper/figures/`.
