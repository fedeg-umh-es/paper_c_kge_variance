# Paper C - Overleaf artifacts

This directory contains the final LaTeX artifacts for Paper C,
generated by `experiments/export_paper_c_latex_artifacts.py` from the
closed experiment outputs under `results/`.

No reruns of the forecasting models are required: the script only
reshapes existing CSVs into LaTeX and copies the existing figures.

## Files to upload to Overleaf

Upload these files preserving the directory layout:

1. `paper/tables.tex`
2. `paper/results_snippets.tex`
3. `paper/figures/fig_paper_c_rmse_skill.png`
4. `paper/figures/fig_paper_c_alpha_vr.png`

## How to insert in `main.tex`

In the preamble (after `\usepackage{graphicx}` and, if available,
`booktabs`):

```latex
\input{results_snippets}  % defines macros and provides figure blocks
```

Then, inside the Results section:

```latex
\input{tables}  % emits Table tab:core and Table tab:appendix
```

The figures are referenced from `results_snippets.tex` with
`\label{fig:rmse}` and `\label{fig:alpha}` and expect the PNGs under
`figures/`.

## Available macros

`results_snippets.tex` defines the following count macros (values
verified against `results/paper_c_main_findings.txt`):

- `\ArimaBetterCount`        -> 7/8
- `\LGBMBetterCount`         -> 8/8
- `\ArimaGainCollapseCount`  -> 7/8
- `\LGBMGainCollapseCount`   -> 8/8
- `\LGBMBeatsArimaCount`     -> 7/8
- `\LGBMLowerAlphaCount`     -> 8/8

It also ships a commented Results/Discussion paragraph ready to copy
into the manuscript.

## Regeneration

From the repository root:

```bash
python3 experiments/export_paper_c_latex_artifacts.py
```

The script is idempotent and overwrites the LaTeX files and figure
copies under `paper/`.
